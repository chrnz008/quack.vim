# quack.vim
The nvim's default dev_theme for vim
its not a exact copy , but looks almost the same and it is made it based of the builtin lunarperche colorscheme

![C](img/rust_example.png)

### Installation

- using [vim-plug](github.com/junegunn/vim-plug)
Add `Plug 'chrnz008/quack.vim'` to vimrc

- manual installation
Copy `colors/quack` to `~/.vim/colors/`

then add the following to
your `~/.vimrc` file:

```
colorscheme quack
```
